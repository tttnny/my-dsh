# @lynn123411/dsh-workspace-tree

DSH 工作区**归档区**：在官方工作区浏览器之上只加一个归档区，其余全部保持官方原样。

官方 `sidebar.workspaces` 是 single 槽且已被官方 `ui-workspace` 独占，无法追加；因此本插件走官方允许的增量入口（与官方 `ui-plugin-manager` 同一套注册方式）：侧栏 `sidebar.panellist` 一枚「归档」图标 + `main`（keyed，key = `workspace-archive`）里一整幅归档面板。官方的工作区列表、会话导航、搜索、拖拽、分组、设置页**一律不动**。

## 特性

- **纯增量，零接管**：不注册 `sidebar.workspaces`，官方工作区浏览器仍是唯一的工作区界面；插件卸载后官方 UI 完全没有痕迹。
- **归档按工作区分组**：归档集合取官方 workspace 控制器的权威 `archivedSessionIds`，按各工作区名下的 `sessionIds` 分组展示；不属于任何工作区的归档会话单独成「未分组」组。subagent 来源的会话与空白草稿不进归档列表（与官方同源判据）。
- **只读阅览**：点击归档会话即在其历史记录中只读浏览——`conversation.composer` 链槽把输入栏替换为只读状态条，并借 `body[data-dswt-archived-session]` 上的 CSS 白名单隐藏分支 / 重试 / 反馈 / 审批等变更类按钮，保留文本浏览与复制；阅览中随时可一键恢复或永久删除。
- **恢复**：单条恢复、组级「恢复全部」、面板级「一键恢复所有」，全部走官方 `workspaces.unarchiveSession` / 官方归档集合，不自己维护第二份归档状态。
- **永久删除（fail-loud 级联）**：单条 / 分组 / 全部删除，逐条执行——物理删除全部成功才从注册表与归档集合剔除；出现真实失败（文件被锁、权限不足等）会把会话留在归档区并逐条列出原因，可幂等重试。删除自动级联清理其派生的全部 Subagent 物理文件、注册关系与 `session_projcache` 投影缓存；级联范围**只认真正的 Subagent**（`origin === "subagent"` / `delegationDepth > 0`），从某条会话 fork 出来的独立会话绝不会被连带删除。目录按**会话真实 id**定位（走拓扑图的 `header.id`）而非常规的目录名拼接，因此被改名或目录名与 id 不一致的会话同样能删净。
- **删除以宿主列表为终局判据（不会掉进「未分组」）**：归档条目是官方侧栏隐藏一条会话的唯一机制，因此只有确认宿主会话列表（`sessionController.list()`，合并进程内 live store 与持久化日志）已不再返回该会话时才剔除条目。归档**不会**把会话移出进程内 live store，刚删完的会话常仍在内存里——此时日志已删、**条目保留且仍在归档区可见**（连同一条说明「N 条仍被当前进程持有，重启后自动清理」的提示），重启 DSH 后自动清理，绝不会作为普通会话出现在「未分组」。
- **归档归官方**：归档动作与门槛都归官方——官方行菜单的「归档」对繁忙会话会先问一次并列出在跑的工作（「停止并归档」）。本插件不写归档集合，只消费官方 `archivedSessionIds`；host 侧破坏性路由另以「目标必须在归档集合内」自证，不依赖前端置灰。
- **失效归档静默清理**：官方列表已不再返回的归档 ID（会话日志已被物理删除的历史残留）在打开面板时自动清理，不显示提示行或按钮。清真空口完全交给 host（以 `sessionController.list()` 为权威存活集），前端只负责触发，绝不用本地列表自行判定。
- **删除记录（墓碑）只记「宿主确已不再持有」的 ID**：仅当宿主列表不再返回该会话时才写入本地墓碑（跨刷新不复活）；宿主仍持有的会话**不写墓碑**，条目继续留在归档区等重启清理。墓碑以 **Host 物理存在性**为权威判据——官方列表仍返回的墓碑会向 `/archive/tombstoneCheck` 查询会话目录是否仍在：目录仍在即会话存活、墓碑系误写（历史残留），自动作废恢复显示；目录已没了才是收敛竞态，继续隐藏直至列表收敛。面板工具条的「清空删除记录」会一次清掉全部本地墓碑（仅在存在墓碑时出现），其文案说明这一语义。
- **中文 / 英文双语**：全部文案走官方 locale 命名空间（`zh` / `en`），语言随界面切换。
- **主题完美适配**：全面使用 DSH 设计系统（`--dsw-*` 语义变量 + `--dsh-*` 布局变量）与 `ui-primitives` 控件（`Button` / `Modal` / `StateDot` / 官方图标），中性描边走 `0.5px`、浮层走 elevation、圆角配 `corner-shape`。

## 安装

```bash
dsh plugin --profile web add @lynn123411/dsh-workspace-tree
```
