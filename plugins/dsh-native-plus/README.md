# @lynn123411/dsh-native-plus

在 DSH 自带的蓝白黑之上，把对话正文的排版与外壳的边角整理得更像一本正经的书。配色一个字不改。

## 功能

- **正文排版**：行高与段落间距两个数字可调，改一下立刻生效。
- **六级标题的蓝阶**：h1 最深、h6 最浅，六档都取宿主蓝阶的两个端点之间插值，深浅两套主题自动翻转。
- **正文装饰**：引用一条蓝线加浅蓝底、表格圆角表头、代码块发丝边框与更紧的圆角、两端淡出的分隔线、蓝色列表标记。
- **外观**：侧栏行与活动标签的圆角收小一档、去掉会话头部接缝、中央列留白，一个开关；内嵌等宽字体，另一个开关。
- **两组配置**：正文排版、外观。共 4 个字段。

## 特性

- **不改任何颜色**：插件不设一个 `--dsw-*` 颜色令牌，也不碰宿主的主题通道。蓝阶、纸面、语法色全部读宿主自己的令牌，宿主换主题时正文跟着换。
- **深浅两套自动跟随**：所有正文颜色由 `color-mix` 从宿主令牌推出来，没有第二份深色表要维护。
- **只有一处声明**：可调项写在 `src/client/schema.ts` 的一张字段表里，宿主半边的 schema、浏览器的投影、配置卡片与自检都从这张表生成，不会出现「卡片上有、投影里没有」。
- **不依赖宿主内部类名**：锚点只有宿主的 `data-slot` 座位名、`data-chat-flow-kind`、`data-row-key`、`data-composer-card` 这类语义属性，CSS Modules 的哈希类名一个都没用。
- **锚点有契约自检**：`scripts/test-anchors.mjs` 会去宿主源码里逐个确认用到的属性名与座位名仍在，并禁止样式表出现哈希类名与写死的色值。
- **字号行高走宿主的令牌**：通过覆盖 `--dsw-font-markdown-*` 改排版，宿主调字号时跟着一起走。
- **标题有对比度闸门**：六档蓝阶的两端在两套纸面上都按 WCAG AA 算一遍。
- **卸载即还原**：样式表按 `data-plugin` 归属键清理，`<html>` 上写的属性与变量一并撤掉。
- **装配、配色落点与验证**：见 [DETAILS.md](./DETAILS.md)。

## 安装

```sh
dsh plugin --profile web add @lynn123411/dsh-native-plus
```
