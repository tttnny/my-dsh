# @lynn123411/dsh-model-submenu

给输入框里的模型选择器加上供应商层级：先在供应商里挑，再挑这个供应商的模型，模型列表与推理等级都留在同一张原生弹层里。

## 功能

- **按供应商挑模型**：点「供应商」进入供应商列表，当前供应商那行显示它正在使用的模型名并带勾选，其余行显示它有多少个模型；再点某个供应商，同一面板内换成它的模型列表，点模型立即提交并关闭。
- **推理等级照原生**：根面板的「推理等级」行进入当前模型的等级列表，选中即提交，「Default」行表示跟随供应商默认；当前模型没有推理等级时不显示这一行。
- **加载与失败有提示**：目录加载中显示刷新提示，加载失败与供应商加载失败都在列表顶部给出提示与「重新加载」，提交被拒时弹出与内置同款的提示气泡。
- **键鼠行为照旧**：方向键在行间移动、Tab 等同回车、Escape 与 Shift+Tab 先退回上一层、在根层才关闭；输入框过窄时触发器只显示图标。

## 特性

- **一级仍是原生两行**：根面板保持内置弹层的两行结构，「供应商」取代原来的「模型」，右侧显示当前供应商名，「推理等级」行原样保留。
- **接管内置座位**：以 `priority: -100` 占据 `conversation.input.model`，外观沿用内置弹层与 `--dsw-*` 主题变量；`/model` 命令面板与设置页不受影响。
- **形态与装配**：bundle 型插件，客户端半边随包内 `cordis.patch.yml` 的根层行服务，profile 侧不用手写补丁；装法、开发副本与验证见 [DETAILS.md](./DETAILS.md)。

## 安装

```bash
dsh plugin --profile web add @lynn123411/dsh-model-submenu
```
