# @lynn123411/dsh-model-submenu

输入框模型菜单的两处增强：第一行「模型」直接打开列出所有供应商模型的弹窗，第二行「推理等级」变成一条可拖动的滑块。

## 功能

- **第一行就是入口**：菜单里的「模型」点下去直接打开弹窗；顶部搜索框同时搜模型名与供应商名，每个有模型的供应商一个标签页。
- **第二行是滑块**：推理等级不再下钻到档位列表，拖动时旋钮跟着指针走、松手吸附到最近一档并切换，键盘左右键逐档调整；轨道上的刻度点数就是该模型可选的档位数，旋钮比轨道大一圈。
- **档位有颜色**：Off 是灰色，往上从蓝走到紫，只有最高档的填充是渐变；输入框触发器上的档位文字跟着同一套颜色走。
- **默认档位是一个状态**：点最左边的「推理等级」四个字切回 provider default——轨道空着、旋钮是空心环，不会被误认成最低档；再拖一下滑块就回到明确档位。
- **收藏靠前**：每行右侧一个星标，点它只切换收藏、不切换模型；收藏表存在浏览器本地，整台浏览器共用一张，收藏的模型排在列表前面。
- **记住每个模型的思考等级**：在弹窗里选中某个模型时，恢复这台浏览器上次为它选的思考等级；该模型不提供那一档时退回它的默认档。
- **元信息一行说清**：模型名下面一行写供应商、上下文窗口、是否支持思考、是否支持图片输入。
- **失败与加载都有交代**：加载中一行文字、加载失败一行文字带「重新加载」、提交被拒弹出提示气泡并留在弹窗里，好让用户换一个。

## 特性

- **宿主渲染菜单，本插件接管前两行**：触发器、菜单面板、标签与档位文字仍由宿主渲染；本插件经 `conversation.input.model.options` 在根菜单打开期间拦截前两行的点击、隐藏原来的模型与推理控件，并把滑块插进第二行。宿主菜单的形状认不出来时它什么都不做，两行退回宿主原来的下钻；模型只声明一档时不挂滑块，那一行原样保留。
- **弹窗住在常驻浮层**：菜单在点击后立刻卸载，所以开合请求经插件自己的 store 交给 `conversation.input.overlay` 里的常驻视图，弹窗不随菜单一起消失。触发器上的档位文字在菜单之外，由同一条浮层里的另一处贡献着色。
- **元信息只写有把握的**：上下文窗口与图片输入读宿主设置页那份共享缓存（`ctx.configForms.describe()`）：上下文窗口只认模型自己声明的值，图片输入在模型没写时按该供应商的默认模态判断；判不出来的与明确不支持的都整段略去，既不写「未知」也不写「不支持」。工具调用在宿主里没有对应字段，一律不写。
- **外观沿用宿主**：弹窗用宿主的 `Modal`，滑块与弹窗的行只写内容与间距，配色取 `--dsw-*` 主题变量。装配与自检清单见 [DETAILS.md](./DETAILS.md)。

## 安装

```bash
dsh plugin --profile web add @lynn123411/dsh-model-submenu
```
