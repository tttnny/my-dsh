# @lynn123411/dsh-model-submenu

把输入框旁的模型选择器换成两层：一层只列当前供应商的模型与思考等级，一层弹窗列全部供应商的模型，可搜、可收藏。

## 功能

- **小菜单只列当前供应商的模型**：顶部一行灰色供应商名，下面按供应商目录排模型；已收藏的排前面并带金色实心星，当前模型带勾选。点模型立即切换并关闭菜单。
- **思考等级就地切换**：一行分段按钮，模型配了几档就显示几档，放不下时这一行横向滚动；点一下只改选中态，菜单关闭时才写入，没有改动就不写。模型不提供思考等级时整行隐藏。
- **弹窗列全部模型**：顶部搜索框（模型名与供应商名都搜）、每个有模型的供应商一个标签页、每行下面一行元信息（供应商、上下文窗口、思考、图片输入）。点模型立即切换；星标只切换收藏，不选中、不关弹窗。
- **收藏按目录顺序靠前**：收藏表存在浏览器本地，整台浏览器共用一张；目录里消失的模型保留收藏，回来时还在。
- **失败与加载都有交代**：加载中一行文字、加载失败一行文字带「重新加载」、提交被拒弹出与内置同款的提示气泡；点模型被拒时小菜单保持打开，关闭菜单时被拒则界面回退到提交前。

## 特性

- **两层各管一件事**：小菜单只服务当前供应商的常用模型与思考等级，换供应商、跨供应商找模型都走「更多模型…」打开的弹窗；宿主自带的 `/model` 命令保持原样。
- **紧凑态照宿主**：输入框放不下一行时只剩图标，跟随宿主给 `conversation.input.model` 的两个显示变量。
- **元信息只写有把握的**：上下文窗口与图片输入读宿主设置页那份共享缓存（`ctx.configForms.describe()`）：上下文窗口只认模型自己声明的值，图片输入在模型没写时按该供应商的默认模态判断；判不出来的与明确不支持的都整段略去，既不写「未知」也不写「不支持」。工具调用在宿主里没有对应字段，一律不写。
- **接管内置座位**：以 `priority: -100` 占据 `conversation.input.model`，外观沿用内置弹层与 `--dsw-*` 主题变量。座位下的 `conversation.input.model.label` 子座位归声明它的注册项所有，接管方不能再声明它，因此第三方往该子座位写的名称/角标扩展在接管期间不会显示；形态与装配见 [DETAILS.md](./DETAILS.md)。

## 安装

```bash
dsh plugin --profile web add @lynn123411/dsh-model-submenu
```
