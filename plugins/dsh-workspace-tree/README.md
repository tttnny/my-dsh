# @lynn123411/dsh-workspace-tree

DSH 工作区树：把左侧栏工作区从「工作区→会话」单层结构升级为基于真实文件系统推导的智能多级树形浏览器——会话环境严格隔离（会话 cwd = 所在目录），支持文件夹与工作区双模式、会话全局重命名、两阶段安全归档、全自动智能级联物理删除，以及「全量展示 + 自动收编 + 隐藏式工作区管理」的一致视图模型。

## 特性

- **会话清晰展示与空白草稿自动回收**：官方列表返回的有效会话一律可见，工作区模式显示活跃会话、归档区显示已归档会话；新建但未发送消息的空白草稿仅在当前处于打开状态时可见，一旦切换到其他会话即瞬间消失并在后台自动回收清理物理记录，彻底杜绝无内容空会话残留。
- **自动收编、无「未分组」**：会话一旦失去工作区归属（如 DSH 升级重置注册表、或经官方入口在任意目录新建），插件在后台自动将其 cwd 注册为工作区（幂等）并挂载会话，「未分组」区块不再存在。
- **隐藏式工作区管理**：工作区操作从「删除注册」改为「移除显示」——仅隐藏该工作区节点（本地记忆），注册、目录文件、会话日志与会话归属均不受影响；被隐藏工作区的归档会话仍在归档区可见可恢复；重新添加同一目录后，工作区连同其会话一起恢复显示；**空工作区自动真注销**——名下已无任何可见会话与归档会话的工作区，移除时直接经官方 workspace/delete RPC 注销注册表记录（同样不删磁盘目录与会话文件，注销失败自动降级为仅隐藏）。
- **文件夹模式**：按真实文件系统浏览目录，支持一键在任意目录新建会话（自动注册工作区，cwd 绑定）或新建子文件夹。
- **工作区模式与智能图标状态**：按目录嵌套关系清晰组织所有工作区与会话列表，支持工作区折叠记忆与状态点聚合透传；工作区与目录展开图标按子树会话状态三级区分——**子树内有会话运行中时呈现蓝色开口文件夹**，**子树内有会话时呈现灰色开口文件夹**，**子树内无会话时呈现白色线框开口文件夹**，运行状态与内容状态一目了然。
- **两阶段安全删除防护**：会话必须先移入归档才能执行永久删除，彻底防止工作区会话日常操作误删；空白草稿不允许归档（归档即不可见又会被回收，等于销毁）；恢复会话时同步清除本地删除墓碑；在归档管理中永久删除时，自动递归级联清理其派生的全部 Subagent 子代理物理文件、注册关系及 `session_projcache` 投影元数据缓存，杜绝任何磁盘与元数据孤儿残留。级联范围**只认真正的 Subagent**（`origin === "subagent"` / `delegationDepth > 0`）——从某条会话 fork 出来的新会话是独立会话，既不会被连带删除，也不会因为它在跑就让归档父会话「被判定正在运行」而删不掉。
- **在 IDE 中打开工作区**：在每个工作区/目录的按钮栏提供一键在外部 IDE（VS Code、CodeBuddy CN、Cursor、Windsurf、Trae、WebStorm、IDEA、PyCharm、Zed、Sublime 或自定义命令）中打开对应工作区的功能；IDE 类型限白名单（未知类型拒绝，绝对路径且存在时放行），自定义命令只读服务端设置，Windows 下含 shell 元字符的路径拒绝执行。
- **配置自由**：在「设置 - 插件 - 工作区树」中自由配置默认打开的 IDE 或自定义启动命令、层级缩进、默认模式等；配置经 DSH 设置服务持久化到 `~/.dsh/settings.yaml`，重启/换端口不丢失。
- **全局会话重命名**：无论会话当前是否处于打开状态，均可通过 Host RPC 实时重命名。
- **归档管理与状态一致性**：提供多级递归归档视图，支持一键恢复与单条/批量永久删除，删除操作与 DSH 工作区数据库、`session_projcache` 投影存储域、内存实例及前端持久化墓碑多重强一致同步；删除被守卫挡下时精确报出**到底是哪一条在挡、为什么、该等什么**（运行中 / 被某个标签页打开 / Subagent 后代在跑），批量删除还会逐条回传跳过原因，且被挡条目一律留在归档中，解除占用后可直接重试；自动识别「幽灵归档」（日志已被删除、host 会话列表不再返回的失效归档 ID）并支持一键从归档列表及 projcache 缓存中清除，保证归档区显示与真实数据一致；墓碑带时间戳，Host 长时间仍返回被删会话（活会话删不掉/删除失败复活）即判定失败并自愈摘碑，杜绝永久误杀。
- **工作区幽灵会话清理**：自动识别各工作区 `sessionIds` 中 host 会话列表已不再返回的残留 ID（日志与缓存均已不存在、仅注册表文件残留引用，如经 DSH 原生入口删除的历史残留），在归档区一键清除；只动注册表、不碰物理目录，当前活跃会话永远豁免。
- **归档只读阅览与就地恢复**：归档区支持点击直接在主视口阅览已归档会话的历史记录，严格执行只读白名单（保留文本浏览与消息/代码复制，自动隐藏分支/重试/反馈/审批按钮并替换输入栏为只读状态条），支持就地一键恢复会话；阅览中的归档会话仍可正常删除——跨客户端占用声明只用于「别的客户端正打开着它」的保护，本标签页自身的声明不挡删除，页面关闭时也会主动释放声明（不再留下最长 5 分钟的假占用）。
- **主题完美适配**：全面接入 DSH 设计系统，完美自适应浅色与深色主题。
- **一键诊断**：设置页（设置 › 插件 › 工作区树）底部可一键复制本机工作区/会话状态（仅元数据，无消息正文），排查侧栏显示问题时粘贴发给开发者。

## 安装

```bash
dsh plugin --profile web add @lynn123411/dsh-workspace-tree
```
