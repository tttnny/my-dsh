# 配置

> 本文档为 [@lynn123411/dsh-chat-translate](../README.md) 的配置说明（自 README 的「## 配置」段迁出，内容保持一致）。

1. **API Key**：打开「设置 - 阅读体验」，在 AI 翻译卡片中直接填写 API Key 并保存（经 DSH 凭据服务写入 `~/.dsh/.credentials.yaml` 的 `TRANSLATE_API_KEY`，权限 0600，保存后立即生效；留空保存 = 清除该键）。也可以手动编辑该文件：

   ```yaml
   refs:
     TRANSLATE_API_KEY: sk-xxx
   ```

   > ⚠️ **注意**：DSH 的凭据加载器要求 refs 键值非空。手动编辑时要么填写真实 Key，要么**直接删除该行**——不要写成 `TRANSLATE_API_KEY: ""` 这类空值，否则 DSH 启动会失败。未配置时插件不翻译，正文保持原文，不会报错。

2. **Base URL 与模型等设置**：在「设置 - 阅读体验」中填写 Base URL（如 `https://api.openai.com/v1` 或 `https://api.deepseek.com/v1`）与模型名（如 `gpt-4o-mini`、`deepseek-chat`），点击「测试 AI 通道」验证。所有设置（开关、超时、Base URL、模型、目标语言）都是本插件在 profile 里的插件配置：写入当前 profile 的 patch（`~/.dsh/profiles/<profile>/cordis.patch.yml`）中 `dsh-chat-translate` 条目的 `config`。开关 `enabled` 有两个入口：设置页总开关，与聊天输入框下方那一行（composer dock）的「译」胶囊——两处读写同一个字段，状态同步；这一行只在会话形态渲染，新建会话的 Hero 形态没有它。字段都是可实时更新的，改完立即生效，可直接编辑该文件，不需重载：

   ```yaml
   - id: dsh-chat-translate
     name: '@lynn123411/dsh-chat-translate'
     config:
       enabled: true
       aiTimeoutMs: 600000
       baseUrl: https://api.deepseek.com/v1
       model: deepseek-chat
       targetLang: zh-Hans
   ```

   > 从 1.2 起，插件不再读写独立的 `~/.dsh/dsh-chat-translate-config.json`：升级后首次加载会自动把旧文件的值迁移进这个配置条目并删除旧文件（若你已在 UI 中改过设置，则以你的设置为准）。

   > 从 2.0 起，`concurrency`、`timeoutMs`、`thinkTimeoutMs`、`aiEnabled`、`bingEnabled`、`thinkEnabled` 与 `channels` 都已退役：这些键在旧版本里描述的能力（工具标题翻译、思考链翻译、Bing 兜底、并发池）已经删除。首次加载会把它们从你的配置条目里清掉，`~/.dsh/dsh-chat-translate/think-cache.json` 也一并删除。`targetLang` 只在这里配置，设置面板不提供入口。

3. **翻译范围与时机**：助手回答的正文一律翻译——「用时 XXX」大折叠块里每一步露出的正文与最终汇总那一步的正文一视同仁；整段中文的块也照送翻译服务，改写还是原样由模型定。判据只看 flow item 是否带 `data-chat-group-part="response"`。回答还在流式输出（markdown 根带 `data-streaming`）时不动，落定后整条自动转中文，不需要点任何按钮。

   - 永不翻译：思考链正文、工具调用标题、工具卡片折叠起来的那一行摘要。
   - 原样保留：代码块（`pre`）及其内部。
   - 混合块（列表项文字 + 子列表 / 代码块）只翻行内文字，嵌套结构留在原位。
   - 失败即保留原文：块内任一片段失败就整块不译，界面上不留提示，控制台留一条警告；失败结果不进缓存，下次滚动重扫时自然重试。
   - 点击某一块的译文原地切回该块原文，再点原文切回译文；块与块互不影响。

4. **请求方式**：客户端按 2048 估算 token 分块，逐块请求、逐块挂载；宿主把相邻片段打包成一个请求（输入上限 4096 估算 token、输出上限 8192 token），单块超过输入上限时按空行、单行、句末依次切开，译回后拼回。同时最多一个在途请求，超时由 `aiTimeoutMs` 控制（默认 600000 毫秒，范围 500–900000）。译文进唯一的缓存池（客户端 500 条、磁盘 1000 条，7 天 TTL）；已命中缓存的块在进入视口时立即显示中文，不发请求。

5. **通道行为**：只有一条通道——Key / Base URL / 模型三者齐备才翻译，缺任何一项都保持原文，不做降级兜底。
