# @lynn123411/dsh-chat-translate

DeepSeek Harness Web 界面的**过程折叠块正文翻译**插件。自动把助手「用时 XXX」那个大折叠块里需要阅读的英文（如 `I traced the failing path to a stale lock file.`）翻成中文，采用非侵入式双语对照渲染（点击译文可原地切回原文），不污染会话上下文。折叠块之外的最终汇总、思考链正文与工具调用行一律不翻，代码块原样保留。配置详见 [docs/配置.md](./docs/配置.md)。

## 特性

- **只翻大折叠块里的正文**：范围判定直接用内核标在 flow item 上的 `data-turn-process-member`（折叠块成员）与 `data-turn-process-answer`（最终汇总）——只翻前者。不做「轮尾行之前」这类位置推断：轮尾行要等轮次结束才出现，进行中的轮次会把折叠块里的正文整片漏掉。折叠块之外的最终汇总、思考链正文、工具调用标题与折叠摘要永不参与，代码块及其内容原样保留。
- **全自动，无需点击**：回答还在流式输出（markdown 根带 `data-streaming`）时不翻，落定后整条转成中文，中文一段一段出现。开关只有一个：设置页里的总开关。
- **中文段落原样保留**：不含拉丁字母的块（整段中文、纯数字、纯标点）不进请求也不占缓存，交付正文里已经写好的中文段落不会被再翻一遍。
- **按块翻译与打包**：正文按 markdown 块级元素切分，混合块（列表项文字 + 子列表 / 代码块）拆成行内片段，嵌套结构留在原位；客户端按 2048 估算 token 分块逐块请求、逐块挂载，宿主把相邻片段打包成一个请求（输入上限 4096 估算 token、输出上限 8192 token），单块超限时按空行、单行、句末依次切开再拼回。
- **失败即保留原文**：块内任一片段失败就整块不译，界面上不留提示，控制台留一条警告；失败的译文不进缓存，下次滚动重扫时会自然重试。
- **非侵入式 DOM 挂载与双语对照**：非侵入式包装保留原始 DOM 节点与 React Fiber 事件系统；点击某一块的译文原地切回该块原文，再点原文切回译文，块与块互不影响。
- **智能内容脱敏与占位符保护**：翻译前对多行代码块、内联代码、URL 链接、文件路径及 CLI 命令行参数做占位符脱敏与鲁棒还原，杜绝代码与路径被误翻译。占位符是 `⟦<随机短码><序号>⟧` 形式的独立片段，构建时会在紧邻拉丁字母的一侧补一个空格，避免译回时与相邻单词粘连。译文只有在每个占位符都按原顺序完整还原时才被采用：占位符被改写、遗失或重复时整条译文作废、退回原文，且绝不写入缓存；升级前旧格式写入的污染译文在读取时被驱逐。
- **单通道：AI 翻译（OpenAI 兼容协议）**：对接任意 OpenAI 兼容的 `chat/completions` 服务（OpenAI、DeepSeek、通义、Ollama、本地 vLLM 等）。Key / Base URL / 模型三者齐备才翻译，缺任何一项都保持原文，不做任何降级兜底。API Key 经 DSH 凭据服务读写 `~/.dsh/.credentials.yaml` 的 `TRANSLATE_API_KEY`，保存后立即生效；Base URL 与模型在设置面板配置。
- **串行请求与熔断保护**：同时最多一个在途请求（长回答按阅读顺序逐段出中文），单次请求超时 `aiTimeoutMs`（默认 600000 毫秒，范围 500–900000），连续失败熔断自愈，7 天 LRU 磁盘缓存 `~/.dsh/dsh-chat-translate/cache.json`。
- **当前会话作用域与视口懒加载**：只翻译当前查看的会话，切换会话自动跟随新内容；回答进入视口（150px 缓冲）才开始翻译，历史会话因此只在真的被读到时才花请求，命中缓存的回答滚到即整条显示中文。
- **DSH 原生配置接入**：配置就是本插件在 profile 里的插件配置——设置面板经 DSH 的共享配置表单（`ctx.configForms`）读写本插件配置条目 `dsh-chat-translate` 的 `config`，用户层落在当前 profile 的 patch；密钥走 DSH `credentials` 服务。无任何自研配置文件。
- **设置面板集成**：设置面板挂在「设置 - 阅读体验」页（本插件贡献其中一张卡片），页内提供总开关、API Key、Base URL、模型、单次请求超时与「测试 AI 通道」。

## 安装

```bash
dsh plugin --profile web add @lynn123411/dsh-chat-translate
```
