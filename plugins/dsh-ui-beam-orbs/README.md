# @lynn123411/dsh-ui-beam-orbs

DSH Web 界面皮肤层插件：在深色主题下提供全局玻璃拟态、Border Beam 边框流光状态机、Thinking Orbs 动态几何思维光球、Pulse 任务清单流光与发送按钮微动效的一体化界面特效方案。背景引擎位于 @lynn123411/dsh-ui-deepseek-bg，与本插件搭配使用可获得完整的沉浸式视觉效果；浅色主题自动恢复官方原版外观。

## 特性

- **深色主题全局玻璃拟态**：为侧边栏、输入框、消息气泡、代码块以及计划、任务清单、提问、审批卡片统一赋予半透明磨砂玻璃质感，覆盖全部高频交互界面；模糊强度提供 6/8/10/12px 四档可选，一键关闭时回退实体底色。
- **Border Beam 五态状态机**：输入框边框流光在待机细线（hairline）、打字呼吸（typing）、计划（planning）、执行（executing）、发送脉冲（pulse）五种状态间随会话进程自动切换，自适应容器圆角，内置 IME 输入法组合事件锁，中文组合输入期间不误触发状态跳变。
- **任务清单流光联动**：Pulse 脉冲流光与任务清单展开、执行中、已完成等状态实时联动，执行中的任务卡片边框呼吸发光，进度一目了然。
- **Thinking Orbs 八种几何预设与工具映射**：基于纯 2D Canvas 实时渲染点阵 3D 几何模型，提供 searching / listening / composing / solving / connecting / shaping / weaving / breathing 八种专用形态（另有 working 轨道基础形态兜底），并与工具调用及思考流一一映射，所见即所做。
- **并发工具聚合提示**：多个工具并发执行时自动聚合计数提示，光球形态平滑过渡，不闪烁、不抖动。
- **状态栏文字联动**：深色主题下回合状态文字启用流光渐变与光晕投影，计划模式自动切换橙色系，并提供 background-clip 兼容降级与 prefers-reduced-motion 静态回退，保证任何环境下文字可读。
- **发送按钮微动效**：发送按钮悬停发光放大、点击弹性反馈等细腻交互反馈。
- **设置页「界面特效」面板**：深度接入 DSH 设置页，配备专属 Sparkles 闪烁星芒光效入口图标，提供 Border Beam 与玻璃效果独立开关、模糊强度选项、GPU 负载估算仪表与 Thinking Orbs 开关，配置通过 localStorage 持久化。
- **浅色主题自动恢复原版**：严格门控深色主题生效范围，浅色主题自动清理 DOM 增强标记并恢复官方原版外观，同时响应系统减弱动效偏好。

## 安装

适配 DSH 0.1.5-rc.1（已实证）。在终端执行以下命令一键安装：

```bash
dsh plugin --profile web add @lynn123411/dsh-ui-beam-orbs
```

建议同步安装背景引擎 @lynn123411/dsh-ui-deepseek-bg，以获得完整的沉浸式界面体验。
