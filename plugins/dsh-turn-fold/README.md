# @lynn123411/dsh-turn-fold

DSH 会话折叠：把每个**已完成**回合的 agent activity（思考 / 工具调用 / 上下文注入）收进一行可展开的折叠栏，只留最终答复正文；折叠栏本身显示该回合的指标。零侵入——只注册官方 `conversation.chat.node` 槽位，不改 DSH 源码、不依赖任何编译产物补丁。

## 特性

- **整回合折叠**：回合结束后，该回合的思考、工具调用与上下文注入收进一行折叠栏，最终答复正文独立可见；展开折叠栏即可逐条回看。出错、被中断、收尾后又有新活动的回合整段保持可见，不会被折叠吞掉。
- **步骤折叠栏**：流式过程中，连续的工具调用与思考按真实交错顺序合成子折叠组，可见的助手正文是硬边界；运行中的组显示工具名与参数摘要并带动画，结束时整组自动收起。
- **闭合标题只给概括性描述**：步骤折叠栏结束后输出纯计数汇总——`读取了N份文件 · 编辑了N份文件 · 搜索了N次 · 执行了N项操作 · 运行了N条命令`，并把段内思考次数以 `思考了N次` 并列追加在末尾。标题不含工具名、参数摘要、文件名或 `[ +N -M ]` 行数变更——展开后自见。
- **展开后逐层缩进**：回合折叠栏与其中的步骤折叠栏同列对齐，层级感由步骤折体内部提供——折体内内容按官方嵌套形态缩进（`margin-left:22px` + `padding-left:8px` + `0.5px` 左细线），深度由渲染层的 `data-dstf-depth` 显式标注，不依赖 DOM 结构推断。
- **折叠栏指标**：回合折叠栏显示耗时、首字时延、消耗 token、tok/s、缓存命中、已折叠步数六项指标；运行中取实时值，回合结束后切换到官方持久化的权威值。数值格式与官方一致（耗时秒位补零、首字 <10 秒一位小数 / ≥10 秒取整、缓存命中 1 位小数且不把部分命中四舍五入成 100%、token 千分位）；消耗 token 与官方统计同口径（含隐藏计费 attempt），tok/s 按官方 decode 口径（Σoutput ÷ Σ(completedTime − firstTokenTime)）实时估算，首字全部取自官方 timing，不用浏览器时钟近似。
- **设置收在「阅读体验」页**：本插件在共享设置页「阅读体验」注册一张卡片（tab「会话折叠」），承载两项设置——回合折叠栏指标字段的逐项显隐、折叠图标风格（动态扑克牌 / 官方 chevron）。两项设置都持久化到 localStorage，刷新后保留。
- **折叠栏图标可换**：前导图标默认内置动态扑克牌（运行中花色循环、收起牌堆、展开扇形），可在设置卡片里切回官方 chevron；花色路径、卡牌几何与动画参数集中在 `icons/default.json`，改后跑 `npm run sync:icons` 注入。
- **折叠方式一行可选**：shadow 官方「对话显示」设置行，提供 Normal / Compact / Turn-Fold 三档——选 Turn-Fold 由本插件接管全部折叠（同时把官方 `transcriptView` 置为 `normal`，避免双重折叠），选 Normal / Compact 则原样委托官方渲染、完全跟随官方设置。
- **与第三方折叠插件共存**：注册前探测同位 slot 占用，被占则自动让位到不冲突的 priority 并提示，不与他人抢同一个渲染位；注册异常软降级、不外泄到启动路径。
- **自定义图标技能**：宿主半边注册 `dsh-turn-fold-customize-icons` 技能，可直接让 AI 代理按流程改折叠栏图标（数据源 → 注入 → 校验 → 刷新）。

## 安装

```bash
dsh plugin --profile web add @lynn123411/dsh-turn-fold
```
