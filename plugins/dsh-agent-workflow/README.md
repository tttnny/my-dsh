# @lynn123411/dsh-agent-workflow

Agent 工作流视图：以用户对话轮次为入口，把 Agent 的模型请求、模型响应与工具调用呈现为清晰的执行链路。插件在「对话 / 轨迹」之外独立增加「工作流」标签页，不替换或修改 DSH 内置的「轨迹」功能。

数据全部来自当前 Session 的真实事件记录（经 uiConversation 投影引擎按 Workflow 目标独立重放生成），系统提示词、消息体、工具定义、响应、工具结果与 Token 统计均为对应模型调用的原始记录；插件只读展示，不向任何模型请求注入消息、提示词或工具。

## 特性

- **按轮次浏览**：左侧固定显示当前 Session 的用户对话轮次（提示词摘要、开始时间、模型调用数、工具调用数与完成状态），支持「加载更早回合」。
- **执行链路可视化**：每次模型调用依次展示 REQUEST 请求 → RESPONSE 响应 → 工具调用卡片，一行内容超出可视区域时横向滚动；模型调用列表使用轻量虚拟化渲染，长链路不挤压页面。
- **完整请求检查**：请求详情分别展示真实记录的 system 提示词、提供方无关的 `messages[]` 消息体与工具定义，JSON 树可逐级展开/收起、一键复制、放大查看。
- **响应内容检查**：展示 reasoning、content、工具调用与响应指标（TTFT / 生成时长 / 输出 Token 等）。
- **工具执行状态**：区分运行中 / 完成 / 失败状态，展示调用参数、执行结果、耗时与错误摘要，含嵌套子工具调用（run_code code-dispatch）。
- **Token 与缓存统计**：分别显示输入、未缓存输入、缓存读取、缓存写入与输出 Token，便于分析上下文复用情况。
- **主题适配**：接入 DSH 设计系统（dsw-alias token），自适应浅色 / 深色主题。

## 安装

```bash
dsh plugin --profile web add @lynn123411/dsh-agent-workflow
```

> 兼容版本：适配 dsh `0.1.2-alpha.1`（客户端模块表 / uiConversation 投影 / uiSession hooks / conversation.view slot 均为该版本契约）。升级 DSH 后需同步升级插件。
