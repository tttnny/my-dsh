# @lynn123411/dsh-notify-user

给模型一条不结束本轮就能向用户汇报进度的通道；连续多次工具调用没汇报时，插件会催它发一条。

## 功能

- **主动汇报**：模型在干活途中调 `notify_user`，对话流里立刻出现一张进度卡——圆点、标题、时间，正文默认展开。本轮不结束、不阻塞，也不等你回答。
- **久不汇报会被催**：连续多次根工具调用没有汇报时，插件在下一步之前注入一条提醒，让模型把当前结论与下一步发出来；汇报过、或开了新回合就重新计数。子代理不催。
- **阈值可改**：插件页的配置卡里改催办阈值，默认 8 次工具调用，0 关闭催办；改完当前会话下一步就生效。
- **折叠可关**：同一张配置卡里决定进度卡带不带折叠键；带折叠键时正文仍默认展开，关掉后正文始终展开、不显示折叠键。

## 特性

- **只加一条通道**：不改系统提示、不改工具策略、不结束本轮；工具结果只有一句确认，正文由模型自己写。
- **卡片在过程里**：进度卡按工具名接管 `tool.call.toolview`，与工具行同处一轮的「工作过程」；本轮进行中始终可见，结束后随过程折叠。标题行是圆点 + 标题 + 折叠键 + 时间，正文缩进在一条竖线里。
- **PTC 下同样成立**：工具出现在 `run_code` 的 SDK 里，程序内的调用画同一张卡；计数只算根调用，程序内部的子调用不算，程序里的 `notify_user` 照样清零。
- **形态与装配**：bundle 型插件，装完即用、在 profile 里不用手写补丁；装配、配置项与验证见 [DETAILS.md](./DETAILS.md)。

## 安装

```sh
dsh plugin --profile web add @lynn123411/dsh-notify-user
```
