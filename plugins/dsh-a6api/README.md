# @lynn123411/dsh-a6api

A6API 多模型聚合站深度接入插件：将 A6API 聚合网关无缝注册为 DSH 原生 LLM 提供商，提供多标签页分类视图（可用模型 / 模型目录 / 账户资产 / 基础配置）、实时美元与人民币真实余额监控、Token 授权模型白名单自动拉取、实时路由探针、全真 1:1 复刻 A6API 官方模型市场维度的全景商户指标卡片与官方 vs 商户价格比对表、标题栏与侧边栏浮层价格波动实时胶囊与「模型市场」直达胶囊均可一键跳转官网，以及后台预热无感加载。

## 特性

- **多标签页优雅布局**：重构并优化设置交互，拆分为「可用模型」、「模型目录」、「账户资产」、「基础配置」四大专属页面，分类清晰、告别页面拥挤。
- **全真官方模型卡片复刻**：1:1 像素级复刻 A6API 官网模型卡片视图，包含品牌图标、模型名、商户 ID、渠道说明、输入/输出/缓存读写单价、实时倍率比值胶囊、实时/24h/7d 阶梯成功率点阵、延迟与缓存命中率进度条、智能标签（稳定/低价/高速/高质/保真）以及真实的固定与禁用操作。
- **给模型固定商家**：卡片一键「固定商家」/「取消固定」，直接调用 A6API 平台固定接口，把当前卡片商家绑定为该模型的服务渠道（优先路由）；固定自动解析并绑定当前 API Key 令牌，异常时自动切换智能优选（平台默认兜底，无多余开关）；检测到模型已固定到其他商家时，卡片自动切换为该固定商家（含价格/健康度指标），无需手动探测；卡片状态实时跟随官网——官网侧解除固定（如不接受涨价）后插件按钮自动还原。
- **商家禁用与恢复**：卡片一键「禁用」当前商家对该模型的服务（路由不再命中），随时「恢复」；固定/禁用状态以徽标展示（已固定 / 已固定到其他商家 / 已禁用）。
- **路由快照时效标注**：每张模型卡片右下角标注「路由快照」时效（该卡片商户数据来自我最近一次路由请求的时刻，相对时间 + 悬停绝对时间），与全网最近成功时间叠放两行；日志中无路由记录的模型显示灰色「从未路由」。
- **官方 vs 商户全景价格对比**：展开卡片即可查看详细渠道说明、智能标签、真实数据徽章、近 100 次样本统计，以及官方基准价与商户实时价在「输入价/输出价/缓存读/缓存写 (1M)」各维度的清晰对比表格。
- **真实账户资产看板与调用明细**：在「账户资产」页面实时呈现真实可用余额（美元及折合人民币）、历史总消耗、累计请求次数，并实时捕获展示近期模型请求的路由明细快照（时间、模型、命中商户渠道、总耗时、Token 消耗及状态）。
- **原生提供商动态注册与一键加入 DSH**：自动向 DSH LLM 运行时注入 `a6api` 目录，在「可用模型」列表点击「添加到 DSH」即可将模型自动增量同步至 `settings.yaml` 与 DSH 对话选择器。
- **节点切换与凭据一站式配置**：在「基础配置」页面支持 CDN 推荐节点（`https://api.a6api.com`）、直连备用节点（`https://a6.a6api.com`）与自定义网关节点自由切换，提供 API Key 与系统访问令牌密码显隐切换及获取教程。
- **DSH 原生配置存储**：全部配置落位 DSH 自有配置体系——凭据（API Key / 系统访问令牌 / userId）存入 `~/.dsh/.credentials.yaml`（0600，env 优先语义），非机密状态（节点 / 模型列表）写入 `settings.yaml` 的 `llm-pi-ai.providers.a6api`，读写走 DSH 原生 `settings` / `credentials` 服务（串行写队列 + schema 校验 + 热发布），不再占用独立配置文件；旧版 `dsh-a6api-config.json` 启动时自动迁移并归档为 `.bak`。启用模型时节点随模型列表一并落盘；移除全部模型时自动移除 DSH 中的 a6api 提供商块（DSH 对手写路由无合法的零模型表示）。
- **价格波动实时胶囊**：标题栏余额右侧常驻「价格波动：n」胶囊（白底，仅数字变色：`0` 绿/`n>0` 红/`--` 灰），基于 `GET /api/marketplace/price-notices` 的待处理条数每 60s 轻轮询（与余额同频，仅计不处置；待处理 = 通知 `relations[].state === 'open'`，即固定渠道存在未被处理/取代的价格变动，兼容显式 `pendingCount` 字段与 `status ∈ open/pending/effective` 的兜底形态），`n>0` 时一键新标签跳 `https://a6api.com/console/token`，未配置/失效或 `0` 时置灰不可点，满足“只监听不处置”的轻量诉求。
- **「模型市场」直达胶囊**：设置页标题栏与侧边栏浮层的胶囊行中，价格波动右侧常驻同款「模型市场」胶囊（白底灰字、hover 变绿），点击新标签直达 `https://a6api.com/models`。
- **侧边栏快捷模型卡片**：主界面左下角（设置按钮上方）常驻「A6api」入口按钮，**任何会话（含子代理）均可展开浮层**，向上弹出当前会话所用模型对应的完整商户卡片（与设置页同一数据源与操作能力：探测/固定/禁用/详情全部可用）；会话切换模型时卡片实时跟随；当前会话未使用 A6api 模型时，模型卡片区域整体置灰且不可交互，顶部账户速览胶囊（余额/价格波动/模型市场）保持正常可用。
- **侧边栏账户速览胶囊**：浮层顶部常驻「账户余额」（纯展示，每 60s 自动同步）、「价格波动」（行为与标题栏一致，可一键跳官网）与「模型市场」（点击新标签直达 `https://a6api.com/models`）三枚同款胶囊，账号级数据与模型卡片无关，加载/空态恒显示。
- **后台预热无感加载**：插件随 DSH 启动即后台预热一次完整状态，之后每 60s 静默整体刷新；服务端 `/state` 将余额/模型列表/日志/固定记录等独立上游调用并行拉取（串行 5 次 RTT → 1 次）—— 侧边栏浮层与设置页打开时数据已就绪，秒开无加载等待。
- **模型目录管理**：「可用模型」右侧新增「模型目录」页——一键「从 A6API 获取市场模型」翻页拉取市场支持的全部模型 ID（参数初始为空），再「从 OpenRouter 一键查询」自动填充 `contextWindow / maxTokens / input`（查不到的保持留空可手动填写，每行也可单独查询；`name` 仅用户手动填写，未填则不写入 DSH）；行内编辑全部采用 DSH `settings.yaml` 原生模型字段（name / contextWindow / maxTokens / input / reasoningEfforts），保存后若该模型已在 DSH 启用则立即重写 `llm-pi-ai.providers.a6api` 对应条目即时生效；支持按「可用（当前令牌白名单）/ 不可用」与「参数已填 / 未填」筛选；可一键「清空目录」（二次确认）后重新从 A6API 获取并重新用 OpenRouter 填充；新获取的模型默认声明 DSH 全部思考档位（off / minimal / low / medium / high / xhigh / max）。内置静态模型目录已移除，所有参数以运行时数据为准（v1.4 起存于 `~/.dsh/dsh-a6api/catalog.json` 插件子目录，与 DSH「组件自建 home 子目录」惯例一致；旧版根目录 `dsh-a6api-catalog.json` 首次加载时自动搬迁并删除），写入 settings.yaml 时缺省字段自动省略（由 DSH 默认值兜底）。
